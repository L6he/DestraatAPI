### Backend-i seadistamine

1. Klooni repo VSC-sse
2. Ava projekti kaust, veendu, et see on usaldatud
3. Menüüribalt vali `Terminal` > `New Terminal`
4. Avanud terminalilt vali paremalt powershell-i asemel dropdown-ist "Command Prompt"
5. Veendu et terminali filepath on backend kaustas, kui ei ole, kirjuta `cd backend`
6. Kui backend kaustas on express puudu, kirjuta `npm install express`
7. Kui backend kaustas on nodemon puudu, kirjuta `npm install nodemon -D`

### Produktsiooni käivitamine
Eelmiste sammude põhjal:
1. Konstrueeri produktsiooni kood käsuga `npm run build`
2. Käivita toodangu kood käsuga `npm run dev`, kui see ei toimi, proovi `npm run start`
